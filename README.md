# 物理学実験補助アプリ

Windowsでの物理学実験レポート作成を補助するアプリの配布専用リポジトリです。

**現在は初回配布の準備中です。インストーラーはまだ公開していません。**

## 主な機能

- 表データから白黒グラフを作成。線形近似などの近似、対数軸、SVG・PNG保存、画像コピー。
- iPadのSafariで描いた図をPCへ転送。
- 写真・スキャン画像をPCへ転送し、画像コピー・PNG保存。
- 手書き数式をPC内で認識し、Wordへ数式としてコピー。

## 初回インストール

配布開始後、[Releases](https://github.com/ftmelon17-alt/physics-lab-releases/releases)から `PhysicsLab-バージョン-Setup.exe` をダウンロードしてください。インストールには、配布者から直接お知らせする合言葉が必要です。合言葉をIssueやコメントへ投稿しないでください。

Pythonの事前インストールは不要となる予定です。対応環境はWindows 64bitです。初回配布前に動作確認を行います。

## 更新

アプリのホームにある「アプリの更新」から正式配布版を確認します。新版があればダウンロードし、ファイル検証後にインストーラーを開きます。更新時も配布用の合言葉が必要です。

グラフの入力表は自動保存されません。更新前に元データとグラフ画像を保存してください。受信画像・数式などの保存データは、更新で保持する設計です。

## 数式認識について

認識精度には限りがあります。数式を丁寧にはっきり書き、認識結果を元画像と照合してください。より高精度な認識を重視する場合は、専用アプリMathpix Snipの利用をおすすめします。

このリポジトリには開発コードや合言葉を置きません。配布物に含まれる第三者ソフトウェアの条件は、同梱のライセンス案内を参照してください。
